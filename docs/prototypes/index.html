Task Management

MVP screen prototypes

Each screen opens on its own. Use the prototype controls in the bottom-right corner to switch the role, the screen state, and the task status. The sample date is 17 Nov 2026, Cairo time.

Sign in and account

  • Sign inEmail and password. States: loading, wrong password, session ended.
    All roles
  • Change passwordForced after a temporary password, or opened from the user menu.
    All roles

Admin

  • UsersList, create, edit, and reset password. The system generates the temporary password and shows it once.
    Admin
  • DepartmentsCreate, rename, assign, change, or remove the Manager.
    Admin

Projects

  • Project tasksTable with filters and search, or a board where drag obeys the status rules. Archive button.
    All roles
  • Project membersAdd and remove members. Removal is blocked when the member has tasks.
    All roles
